Good to know.

What is Krill Bot?

A free, open-source Krillion Puffer Party cheat and answer helper, installed as a Violentmonkey userscript. It offers candidate answers and tracks accepted, pending, and rejected answers across category changes.

Do I need Ollama or a GPU?

Ollama is optional. Archive and dictionary suggestions work without a model or GPU. Running Qwen3 8B locally needs enough memory for the model; speed depends on your hardware. See the local AI guide.

Does it automatically play or guarantee scores?

No. Selecting a suggestion fills the input; you submit manually. Historical scores are not predictions of current Party scores. Dictionary and AI answers may be rejected.

Where does my data go?

The script downloads public word-list and archive data from GitHub. When generation is needed, category and candidate text is sent to local Ollama at 127.0.0.1. Imported answers and caches stay in Violentmonkey storage. Read the permission details.

Has it been verified in a live game?

The repository includes regression tests against observed client message shapes. These do not establish a verified live Violentmonkey session. Browser injection and game changes can affect compatibility. Use Diagnostics to check actual feed capture.

Is this an official Krillion tool?

No. This independent project is unaffiliated with Krillion, Violentmonkey, Ollama, or Qwen. Report script issues in the project issue tracker.
