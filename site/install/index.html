Install Krill Bot with Violentmonkey.

Get the Krillion Puffer Party answer helper into your browser. Archive and dictionary suggestions work without Ollama.

Install the userscript

  1. Use a browser supported by Violentmonkey and install the extension from its official download page. Browser support for the extension is separate from verification of this script’s compatibility.
  2. Open the direct Krill Bot userscript link. With the extension enabled, the link should open Violentmonkey’s installation screen.
  3. Review the source, matching sites, and requested permissions. The script manager displays the internal name krill_bot. Choose Install.
  4. Open Krillion and fully reload the tab. Enter Puffer Party so network hooks can attach to new connections.
  5. When suggestions appear, click one or press Alt+1–5 to fill the answer input. Check it and submit yourself. Filling an answer never submits it.

Start without AI. No Ollama installation, model download, or cloud account is required for historical archive and dictionary suggestions.

If the install link displays code

Your browser may display or download the JavaScript instead of opening an installation screen. Use the manual route:

  1. Open the Violentmonkey dashboard and create a new script.
  2. Open the complete userscript source and copy all of it, including the metadata block beginning // ==UserScript==.
  3. Replace the entire new-script template with that source, save, and keep the script enabled.
  4. Fully reload the Krillion tab and reopen Party. Keep only one copy of the script enabled.

Updates and existing installations

Back up/export your script and storage first. For installations with the name krill_bot and namespace krill_bot.local, open the direct installation link again or use Violentmonkey’s update command. The identity stays the same so the manager can recognize the existing installation. Download and update metadata point to the repository’s main-branch userscript.

If you use an older script with another identity, edit that existing installation, replace its full contents, and save. The script copies validated older cache keys to the current keys when they exist in the same storage. A separate new installation cannot automatically read another script’s storage.

Keep only one copy enabled, then fully reload the game. For the full history, see the implementation notes.

When the panel or answers are missing

The panel does not appear

Check that Violentmonkey and the script are enabled and allowed to run on Krillion. Fully reload the tab after installation. Open Puffer Party; the script’s Party adapter is not a promise of support for every game mode.

The panel appears but tracking stays empty

Open Diagnostics and check the feed indicator and confirmation evidence. An installed hook does not establish that game traffic was captured. Missing patch history waits for a full snapshot rather than guessing; a full reload can reconnect the game.

A suggested answer gets rejected

Historical scores can differ in Party. The literal word parser supports only some restrictions, and dictionary or model suggestions may fail game validation. Try another candidate; no score or acceptance is guaranteed.

AI suggestions do not load

Archive and dictionary suggestions still work. If you want generation, follow the Ollama and Qwen3 guide.

Report a problem

The regression suite is not evidence of a verified live Violentmonkey session. Browser injection and game updates can affect behavior. Open an issue with your script version, browser, Violentmonkey version, and a redacted example. Do not include player keys, authentication tokens, private chat, or room invite links.

Disable or remove

Disable the script in Violentmonkey, then fully reload the game to remove its hooks and panel from that tab. To remove it completely, delete the script in the manager after exporting any stored answers you want to preserve.
